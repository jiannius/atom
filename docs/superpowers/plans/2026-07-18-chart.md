# `<atom:chart>` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extract a standalone `<atom:chart type=bar|area|trend>` component wrapping atom's existing ApexCharts Alpine factories, fix two latent `area.js` bugs, and refactor `<atom:card variant=chart>` to delegate to it.

**Architecture:** A single anonymous Blade component (`components/chart.blade.php`) maps a `type` prop to one of three already-registered Alpine factories (`chartBar`/`chartArea`/`chartTrend`) and emits one `x-data` div — the same config the card builds inline today. The card's chart branch is refactored to call the new component; the JS factories are shared and unchanged except for bug fixes in `area.js`.

**Tech Stack:** Laravel anonymous Blade components, Alpine.js, ApexCharts (dynamic `import`, already a dependency), Pest + Orchestra Testbench, Playwright.

## Global Constraints

- Namespace/tag: component is reachable as `<atom:chart>` (anonymous component in `components/`).
- PHP style: curly braces on all control structures; `match` for the type→factory map (atom convention).
- Data shapes (caller's responsibility, documented): `bar`/`area` → `[['label'=>, 'value'=>, 'tooltip'=>], …]`; `trend` → plain numeric array `[8, 12, …]`.
- Default-class-override convention: apply a default only when the caller passed none, via `str($attributes->get('class'))->is('*h-*')` (mirrors `components/icon/_wrapper.blade.php:7`).
- Front-end rule: JS changes require `npm run build` + committing `dist/`.
- Worktree deps: real `composer install` **and** `npm ci` in the worktree (symlinked vendor resolves to main's dist — atom-testing gotcha). Do this once before running tests/build.
- Do NOT touch the `variant=stats` branch or its `chartTrend` sparkline.
- Cannot put literal `<` / `>` inside a `<atom:...>` tag's attribute (TagCompiler chokes) — keep docs descriptions free of them.
- Ship as **v3.15.0** via draft PR from branch `worktree-chart`.

### Task 1: `<atom:chart>` component + render tests

**Files:**
- Create: `components/chart.blade.php`
- Test: `tests/Feature/ChartTest.php`

**Interfaces:**
- Consumes: existing Alpine factories `chartBar` / `chartArea` / `chartTrend` (registered in `resources/js/atom.js`); no code dependency, only the emitted `x-data` name.
- Produces: `<atom:chart>` with props `type` (default `'bar'`), `data` (default `[]`), `color` (null), `max` (null), `min` (null). Emits a div carrying `data-atom-chart`, `data-atom-chart-type="{type}"`, and `x-data="{factory}({ data, color, max, min })"`. Default height `h-64` (bar/area) / `h-16` (trend), suppressed when caller passed any `h-*` class.

- [ ] **Step 1: Write the failing test**

Create `tests/Feature/ChartTest.php`:

```php
<?php

use Illuminate\Support\ViewErrorBag;

beforeEach(function () {
    view()->share('errors', new ViewErrorBag);
});

describe('chart', function () {
    $barData = [['label' => 'Mon', 'value' => 10, 'tooltip' => '10 sales']];

    it('renders a bar chart by default', function () use ($barData) {
        $html = renderBlade('<atom:chart :data="$data"/>', ['data' => $barData]);

        expect($html)
            ->toContain('data-atom-chart')
            ->toContain('data-atom-chart-type="bar"')
            ->toContain('chartBar(')
            ->toContain('h-64');
    });

    it('maps type=area to the chartArea factory', function () use ($barData) {
        $html = renderBlade('<atom:chart type="area" :data="$data"/>', ['data' => $barData]);

        expect($html)
            ->toContain('data-atom-chart-type="area"')
            ->toContain('chartArea(')
            ->toContain('h-64');
    });

    it('maps type=trend to the chartTrend factory with a sparkline height', function () {
        $html = renderBlade('<atom:chart type="trend" :data="$data"/>', ['data' => [8, 12, 9, 14]]);

        expect($html)
            ->toContain('data-atom-chart-type="trend"')
            ->toContain('chartTrend(')
            ->toContain('h-16');
    });

    it('lets a caller override the default height', function () use ($barData) {
        $html = renderBlade('<atom:chart :data="$data" class="h-96"/>', ['data' => $barData]);

        expect($html)
            ->toContain('h-96')
            ->not->toContain('h-64');
    });

    it('serialises color, max and min into the x-data config', function () use ($barData) {
        $html = renderBlade(
            '<atom:chart :data="$data" color="green" :max="$max" :min="$min"/>',
            ['data' => $barData, 'max' => ['value' => 100, 'label' => 'Goal'], 'min' => ['value' => 0]],
        );

        expect($html)
            ->toContain('green')
            ->toContain('Goal')
            ->toContain('100');
    });
});
```

- [ ] **Step 3: Write the component**

```blade
@props([
    'type' => 'bar',
    'data' => [],
    'color' => null,
    'max' => null,
    'min' => null,
])

@php
$factory = match ($type) {
    'area' => 'chartArea',
    'trend' => 'chartTrend',
    default => 'chartBar',
};

$height = str($attributes->get('class'))->is('*h-*')
    ? ''
    : ($type === 'trend' ? 'h-16' : 'h-64');
@endphp

<div
    {{ $attributes->class(['w-full', $height]) }}
    data-atom-chart
    data-atom-chart-type="{{ $type }}"
    x-data="{{ $factory }}({ data: @js($data), color: @js($color), max: @js($max), min: @js($min) })"
></div>
```

**Interfaces:**
- Consumes: nothing new.
- Produces: a working `chartArea` factory (area charts previously never rendered). Behaviour now matches `bar.js`: `this.chart.render()` in `$nextTick`, plus a `darkmode-changed` listener re-running `setColors()`.

- [ ] **Step 1: Read the current broken block**

Run: `grep -n 'chart.render\|darkmode-changed\|nextTick' resources/js/alpinejs/chart/area.js`
Expected: shows `chart.render()` (bare `chart`, undefined) inside `$nextTick`, and **no** `darkmode-changed` listener.

- [ ] **Step 2: Apply the fix**

In `resources/js/alpinejs/chart/area.js`, replace:

```js
                this.$nextTick(() => {
                    chart.render()
                    this.setColors()
                })
            })
```

with:

```js
                this.$nextTick(() => {
                    this.chart.render()
                    this.setColors()
                })

                document.addEventListener('darkmode-changed', () => this.setColors())
            })
```

(The added listener sits inside the `import('apexcharts').then(...)` callback, exactly as in `bar.js`.)

- [ ] **Step 3: Verify the edit**

Run: `grep -n 'this.chart.render\|darkmode-changed' resources/js/alpinejs/chart/area.js`
Expected: both lines present; no remaining bare `chart.render()`.

(Runtime verification lands in Task 5's e2e once `dist/` is rebuilt — this JS is not unit-tested.)

- [ ] **Step 4: Commit**
